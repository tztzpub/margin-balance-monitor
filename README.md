# 融资融券与市场乖离率

[打开网页](https://tztzpub.github.io/margin-balance-monitor/)

三张同步时间轴图：融资余额、融券余额的20个交易日变化率，以及七个标的的60日乖离率。
支持起止日期、YTD、常用时间范围、同步游标和独立纵轴缩放。

数据来自东方财富 Choice 的全市场账户统计接口 `RPTA_WEB_MARGIN_DAILYTRADE`。
变化率为当日余额除以20个交易日前余额减一，先使用完整历史计算，再筛选展示区间。

独立的ETF实时看板追踪截图中的12只ETF；直接从浏览器读取腾讯公共行情，每15秒刷新。显示价格、涨跌幅、当日和昨日成交额、近4日平均成交额、同刻倍数、最强15分钟和最长连续放量。历史分钟接口只提供前4日，未用成交量乘价格近似成交额，也不冒称20日均值。倍数按历史相同分钟比较，只纳入已完成15分钟窗口，不跨午休。行情失败/延迟有独立标记；切到后台暂停请求，返回自动更新。支持列排序、暂停和立即刷新。

乖离率图保留原有七条：中证全指、科创50ETF（588000）、创业板ETF（159915）、沪深300、中证500、中证1000、中证2000，可分别勾选。ETF看板不受下方历史图的日期选择影响。
每日乖离率 = 当日收盘价 / 截至当日的60个交易日收盘价均值 − 1。
悬停显示当日收盘价、价格日期和MA60。
行情来自腾讯日线与中证指数官方历史接口；ETF使用未复权成交价，分红和份额折算可能造成历史乖离率跳变。盘中更新只纳入此前已完成的交易日。
每条序列满60条历史记录后才出值。已核实的停牌日（包括159915持有人大会、159919／510500／512100份额折算）按实际交易日序列滚动，不填造行情；核实来源留在market.py对应记录。
同一图各序列计算口径一致，区间选择不改变计算窗口。

工作站 systemd 定时触发 GitHub Actions：工作日北京时间08:35、15:10，以及16:35至23:35每小时检查数据并发布到GitHub Pages。定时器为 `margin-balance-refresh.timer`，定义保存在 `systemd/`。
GitHub 自带08:35、18:35、22:35定时作为备用，其实际启动时间可能延迟。行情和融资融券分别显示最新数据日期；余额以源接口正式发布为准，不用估算填补。也可以在Actions中手动运行 `Refresh and publish`。
接口失败、历史缺失或校验不通过时，任务失败，线上保留上次成功发布的页面。
数据日期与最近核查时间在页面上分别显示。

本地生成：

```sh
pip install -r requirements.txt
python refresh.py
python build.py
```

`build.py` 是唯一页面生成器，`index.html` 为自包含输出，可单独下载打开。
