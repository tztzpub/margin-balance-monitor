# 融资融券与市场乖离率

[打开网页](https://tztzpub.github.io/margin-balance-monitor/)

三张同步时间轴图：融资余额、融券余额的20个交易日变化率，以及七个标的的60日乖离率。
支持起止日期、YTD、常用时间范围、同步游标和独立纵轴缩放。

数据来自东方财富 Choice 的全市场账户统计接口 `RPTA_WEB_MARGIN_DAILYTRADE`。
变化率为当日余额除以20个交易日前余额减一，先使用完整历史计算，再筛选展示区间。

乖离率图包括中证全指、科创50ETF（588000）、创业板ETF（159915）、沪深300、中证500、中证1000、中证2000，可分别勾选。
计算严格采用昨收填充口径：日期 t 使用 t−59 至 t−1 的59个收盘价，再加入第二份 t−1 收盘价，构成60日均线；BIAS = 昨收 / 该均线 − 1。
不使用 t 日实际收盘价。悬停同时显示计算所用的昨收、价格日期和均线值。
行情来自腾讯日线与中证指数官方历史接口；ETF使用未复权成交价。
每条序列满59条历史记录后才出值。159915 在2021-02-08经公告停牌，按其实际交易日序列滚动，不填造行情。
同一图各序列计算口径一致，区间选择不改变计算窗口。

GitHub Actions 每天北京时间08:35、18:35、22:35检查数据并发布到GitHub Pages；
实际启动时间由GitHub调度。也可以在Actions中手动运行 `Refresh and publish`。
接口失败、历史缺失或校验不通过时，任务失败，线上保留上次成功发布的页面。
数据日期与最近核查时间在页面上分别显示。

本地生成：

```sh
pip install -r requirements.txt
python refresh.py
python build.py
```

`build.py` 是唯一页面生成器，`index.html` 为自包含输出，可单独下载打开。
