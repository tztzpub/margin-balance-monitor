# 融资融券与市场乖离率

[打开网页](https://tztzpub.github.io/margin-balance-monitor/)

三张同步时间轴图：融资余额、融券余额的20个交易日变化率，以及17个标的的60日乖离率。
支持起止日期、YTD、常用时间范围、同步游标和独立纵轴缩放。

数据来自东方财富 Choice 的全市场账户统计接口 `RPTA_WEB_MARGIN_DAILYTRADE`。
变化率为当日余额除以20个交易日前余额减一，先使用完整历史计算，再筛选展示区间。

乖离率图包括中证全指、科创50ETF（588000）、创业板ETF（159915）、沪深300、中证500、中证1000、中证2000，可分别勾选。另纳入沪深300ETF嘉实（159919）、中证500ETF南方（510500）、沪深300ETF华泰柏瑞（510300）、中证1000ETF南方（512100）、A500ETF富国（563220）、创业板50ETF华安（159949）、中证A500ETF景顺（159353）、沪深300ETF华夏（510330）、创业板ETF天弘（159977）、上证50ETF华夏（510050）。新增ETF默认不叠加曲线，可按需勾选；代码随名称显示。新增序列首次自动补历史，后续随原定时任务更新。
每日乖离率 = 当日收盘价 / 截至当日的60个交易日收盘价均值 − 1。
悬停显示当日收盘价、价格日期和MA60。
行情来自腾讯日线与中证指数官方历史接口；ETF使用未复权成交价，分红和份额折算可能造成历史乖离率跳变。盘中更新只纳入此前已完成的交易日。
每条序列满60条历史记录后才出值。已核实的停牌日（包括159915持有人大会、159919／510500／512100份额折算）按实际交易日序列滚动，不填造行情；核实来源留在market.py对应记录。
同一图各序列计算口径一致，区间选择不改变计算窗口。

GitHub Actions 每天北京时间08:35、18:35、22:35检查数据并发布到GitHub Pages；
实际启动时间由GitHub调度。也可以在Actions中手动运行 `Refresh and publish`。
接口失败、历史缺失或校验不通过时，任务失败，线上保留上次成功发布的页面。
数据日期与最近核查时间在页面上分别显示。

本地生成：

```sh
pip install -r requirements.txt
python refresh.py
python build.py
```

`build.py` 是唯一页面生成器，`index.html` 为自包含输出，可单独下载打开。
